# SelfMinifier

SelfMinifier 0.4.0 é uma ferramenta Windows para minificação controlada de JavaScript e CSS, com análise prévia, confirmação explícita, backup/restauração, histórico, integridade SHA-256 e documentação offline.

As fontes autoritativas do produto ficam em [`Especificacoes/`](Especificacoes/). Os manuais para uso e manutenção ficam em [`Documentacao/Fonte/`](Documentacao/Fonte/); o HTML offline é gerado com `npm.cmd run build:docs` e publicado em [`Documentacao/Gerada/`](Documentacao/Gerada/).

Para iniciar, use `Executar.cmd`. A distribuição normal funciona offline com Node.js homologado e dependências empacotadas. Configuração, instalação, menus, restauração, logs, limites e manutenção estão descritos nos manuais; este README não duplica essas instruções.
