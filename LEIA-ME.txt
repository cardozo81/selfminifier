SelfMinifier 0.4.0

Ferramenta Windows para minificação controlada de JavaScript e CSS, com confirmação explícita, análise prévia, backup/restauração, histórico e integridade SHA-256.

Início: execute `Executar.cmd`.

Documentação:
- Manual do Usuário: `Documentacao\Gerada\Manual-Usuario\index.html`
- Manual Técnico e de Manutenção: `Documentacao\Gerada\Manual-Tecnico\index.html`
- Fontes Markdown: `Documentacao\Fonte\`
- Especificações: `Especificacoes\`

Para regenerar o HTML offline, execute `npm.cmd run build:docs`. Consulte os manuais para requisitos, configuração, segurança, restauração, relatórios, logs e problemas comuns.
